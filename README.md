## Files

index.html      the website

because the photos and videos live in the `assets` folder.

## Publish on GitHub Pages

1. Upload `index.html`, the `assets` folder and `.nojekyll` to the repo root
   (not inside another folder)
2. Settings → Pages → Deploy from a branch → `main` → `/ (root)`
3. Wait 1–2 minutes and open the link

The repository must be **public**.

**If pictures do not appear:** open the repo and check that `assets` is there
with 14 files inside. That is nearly always the cause.
