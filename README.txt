--------------------------------------------------------------
1. WHAT TO UPLOAD  /  ماذا ترفع
--------------------------------------------------------------
Upload these TWO items to your hosting root (public_html):

    index.html
    assets/            (the whole folder)

That is the whole website. Nothing else is needed.
ارفع الملف والمجلد فقط إلى المجلد الرئيسي للاستضافة.

--------------------------------------------------------------
2. THE SECOND FILE  /  الملف الثاني
--------------------------------------------------------------
    index-offline-single-file.html

Everything (videos + photos) is embedded inside this one file.
Use it to show the site from a laptop, a USB stick, or an email
attachment with NO internet and NO server. Just double-click it.

Do NOT upload this one to the server — it is slower.
هذا الملف للعرض دون إنترنت فقط. لا ترفعه على الاستضافة.

--------------------------------------------------------------
3. ADMIN PANEL  /  لوحة التحكم
--------------------------------------------------------------
Open the site, scroll to the very bottom, click the LOCK icon
next to the language button.

    Email    : ahmed.k@steelbuilderuae.com

Change the password from the panel after the first login.

HOW TO PUBLISH YOUR EDITS  /  كيف تنشر التعديلات
    1. Log in and make your changes
    2. Press  حفظ  (Save)
    3. Press  تصدير الموقع  (Export) -> downloads a new index.html
    4. Upload that new index.html to the server, replacing the old one

Edits are NOT live until you do step 3 and 4.
التعديلات لا تظهر للزوار إلا بعد التصدير ورفع الملف الجديد.

WARNING / تنبيه
This login is a convenience lock, not real security. The password
check happens inside the visitor's browser, so a determined person
can read it from the page source. Do not treat it as protection
for anything sensitive.
